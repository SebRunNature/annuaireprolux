Loisirs au Luxembourg

112 entreprises

Cette page réunit 112 fiches classées parmi les loisirs, réparties dans 62 communes. Les communes les plus représentées sont Luxembourg (26), Dudelange (4) et Echternach (4). Côté coordonnées, sur 112 fiches : 70 ont un site web, 34 un numéro de téléphone et 20 une adresse e-mail. Les fiches sont classées par ordre alphabétique. Chaque fiche ouvre une page détaillée, avec l'adresse, l'itinéraire et les horaires quand ils sont connus. 111 de ces fiches viennent d'OpenStreetMap, les autres d'inscriptions faites sur le site.

Une information est fausse ou manquante ? Signalez-la à l'éditeur, ou ajoutez votre entreprise gratuitement si vous exercez ce métier. Dans la même catégorie (beauté, mode et loisirs) : coiffeurs, instituts de beauté et salles de sport.
